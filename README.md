# inno-medical-claims-guard

**تشخیص ناهنجاری در اسناد بیمه**

> وضعیت: **TRL 4** — نمونه‌ی آزمایشگاهی با اعتبارسنجی اجزا روی **داده‌ی مصنوعی** (بدون داده‌ی بیمار). برای ارزیابی بالینی یا میدانی آماده نیست. ← [مستندات TRL](docs/TRL.md)

## نیاز شناسایی‌شده
رشد هزینه‌های درمان، تخلف در نسخه و صورت‌حساب و بار بازرسی دستی.

## محصول
تشخیص الگوهای غیرعادی در اسناد بیمه‌ای و اولویت‌بندی بازرسی.

## کاربران و ذی‌نفعان
واحد بیمه و درآمد بیمارستان، بیمه‌ها، وزارت بهداشت

## قابلیت‌های هدف
- امتیازدهی ناهنجاری به هر سند
- توضیح دلیل پرچم‌گذاری برای بازرس
- گزارش روند تخلف به تفکیک مرکز

## داده
اقلام صورت‌حساب، کد خدمت، تعرفه، پزشک، تاریخ. در مراحل اولیه فقط داده‌ی مصنوعی یا بی‌نام‌شده استفاده می‌شود.

## ریسک‌ها و محدودیت‌ها
پرچم اشتباه می‌تواند به اتهام ناروا برسد؛ تصمیم نهایی فقط با بازرس انسانی.

## مسیر پیشنهادی
1. ✅ TRL 1 → 2: تعریف نیاز و معیار موفقیت (جدول معیارها در [docs/TRL.md](docs/TRL.md)).
2. ✅ TRL 3: نمونه‌ی آزمایشگاهی روی داده‌ی مصنوعی همراه با تست.
3. ✅ TRL 4: اعتبارسنجی اجزا در آزمایشگاه با تست‌های خودکار (CI روی هر push).
4. ⬜ TRL 5: اعتبارسنجی در محیط مرتبط با داده‌ی واقعی بی‌نام‌شده — نیازمندی‌ها در [docs/TRL.md](docs/TRL.md).

## یادداشت
این ریپو بخشی از مجموعه‌ی `inno-medical-*` برای دانشگاه‌های علوم پزشکی و وزارت بهداشت است. هیچ‌یک از خروجی‌ها جایگزین قضاوت بالینی نیست.

## راه‌اندازی سریع
```bash
pip install -r requirements.txt           # فقط numpy
export PYTHONPATH=src
python -m inno_medical_claims_guard generate --out data/sample # تولید داده‌ی مصنوعی (قطعی با seed)
python -m inno_medical_claims_guard validate                   # اجرای معیارهای TRL 4 روی ۳ seed
python -m inno_medical_claims_guard demo
python -m unittest discover -s tests -v
```

## آنچه پیاده‌سازی شده
امتیاز ناهنجاری از سه سیگنال (قیمت واحد نسبت به میانه‌ی همان خدمت، تعداد غیرعادی، تکرار سند) با «دلیل» قابل‌خواندن؛ روند مراکز.
