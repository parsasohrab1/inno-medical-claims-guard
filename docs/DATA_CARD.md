# کارت داده — inno-medical-claims-guard

- **منبع:** کاملاً مصنوعی؛ تولید با `python -m inno_medical_claims_guard generate --seed N` (قطعی). هیچ داده‌ی بیمار، شخص یا مرکز واقعی در ریپو نیست.
- **نمونه‌ی ذخیره‌شده:** `data/sample/*.csv` (seed=0).
- **فرض‌ها:** ۴۰۰۰ سند، ۴۰ کد خدمت، ۲۵ مرکز؛ ۵٪ ناهنجاری تزریق‌شده (اضافه‌صورت‌کردن، تکرار، تعداد زیاد). الگوهای تقلب پیچیده‌تر در داده نیست.
- **استفاده‌ی مجاز:** توسعه و آزمون نرم‌افزار. استفاده برای آموزش/ارزیابی مدل بالینی یا هر تصمیم واقعی مجاز نیست.
- **حریم خصوصی:** هنگام ورود داده‌ی واقعی باید بی‌نام‌سازی، مجوز اخلاق و توافق‌نامه‌ی اشتراک داده انجام شود.
